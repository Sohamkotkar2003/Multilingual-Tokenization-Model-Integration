# Himachali Lite Adapter

## Bootstrap Information

- **Bootstrapped from:** Hindi
- **Language similarity:** 75%
- **Note:** Himachali is a Pahari dialect using Devanagari

## Usage

This adapter was created by copying the Gurukul Lite adapter, which already
supports Hindi. 

Since Himachali is 75% similar to Hindi,
the model can generate text in Himachali using the same patterns.

## Performance

- **Expected accuracy:** 60-70% (bootstrapped, not specifically trained)
- **Can be improved:** Train on native Himachali data when available

## Training Data

- Uses Gurukul Lite's training data (21 Indian languages)
- Relies on cross-lingual transfer from Hindi
