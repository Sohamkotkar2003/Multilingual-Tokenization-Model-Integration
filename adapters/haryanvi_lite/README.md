# Haryanvi Lite Adapter

## Bootstrap Information

- **Bootstrapped from:** Hindi
- **Language similarity:** 90%
- **Note:** Haryanvi is extremely close to standard Hindi

## Usage

This adapter was created by copying the Gurukul Lite adapter, which already
supports Hindi. 

Since Haryanvi is 90% similar to Hindi,
the model can generate text in Haryanvi using the same patterns.

## Performance

- **Expected accuracy:** 60-70% (bootstrapped, not specifically trained)
- **Can be improved:** Train on native Haryanvi data when available

## Training Data

- Uses Gurukul Lite's training data (21 Indian languages)
- Relies on cross-lingual transfer from Hindi
