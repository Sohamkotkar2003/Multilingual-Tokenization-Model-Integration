# Chhattisgarhi Lite Adapter

## Bootstrap Information

- **Bootstrapped from:** Hindi
- **Language similarity:** 80%
- **Note:** Chhattisgarhi is a Hindi dialect

## Usage

This adapter was created by copying the Gurukul Lite adapter, which already
supports Hindi. 

Since Chhattisgarhi is 80% similar to Hindi,
the model can generate text in Chhattisgarhi using the same patterns.

## Performance

- **Expected accuracy:** 60-70% (bootstrapped, not specifically trained)
- **Can be improved:** Train on native Chhattisgarhi data when available

## Training Data

- Uses Gurukul Lite's training data (21 Indian languages)
- Relies on cross-lingual transfer from Hindi
