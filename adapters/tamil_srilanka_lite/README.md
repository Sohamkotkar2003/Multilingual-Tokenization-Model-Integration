# Tamil Srilanka Lite Adapter

## Bootstrap Information

- **Bootstrapped from:** Tamil
- **Language similarity:** 98%
- **Note:** Sri Lankan Tamil is virtually identical to Indian Tamil

## Usage

This adapter was created by copying the Gurukul Lite adapter, which already
supports Tamil. 

Since Tamil is 98% similar to Tamil,
the model can generate text in Tamil using the same patterns.

## Performance

- **Expected accuracy:** 60-70% (bootstrapped, not specifically trained)
- **Can be improved:** Train on native Tamil data when available

## Training Data

- Uses Gurukul Lite's training data (21 Indian languages)
- Relies on cross-lingual transfer from Tamil
