# Magahi Lite Adapter

## Bootstrap Information

- **Bootstrapped from:** Hindi + Maithili
- **Language similarity:** 80%
- **Note:** Magahi is between Hindi and Maithili

## Usage

This adapter was created by copying the Gurukul Lite adapter, which already
supports Hindi + Maithili. 

Since Magahi is 80% similar to Hindi + Maithili,
the model can generate text in Magahi using the same patterns.

## Performance

- **Expected accuracy:** 60-70% (bootstrapped, not specifically trained)
- **Can be improved:** Train on native Magahi data when available

## Training Data

- Uses Gurukul Lite's training data (21 Indian languages)
- Relies on cross-lingual transfer from Hindi + Maithili
