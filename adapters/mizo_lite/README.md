# Mizo Lite Adapter

## Bootstrap Information

- **Bootstrapped from:** Bengali
- **Language similarity:** 40%
- **Note:** Mizo is Tibeto-Burman but has Bengali influence

## Usage

This adapter was created by copying the Gurukul Lite adapter, which already
supports Bengali. 

Since Mizo is 40% similar to Bengali,
the model can generate text in Mizo using the same patterns.

## Performance

- **Expected accuracy:** 60-70% (bootstrapped, not specifically trained)
- **Can be improved:** Train on native Mizo data when available

## Training Data

- Uses Gurukul Lite's training data (21 Indian languages)
- Relies on cross-lingual transfer from Bengali
