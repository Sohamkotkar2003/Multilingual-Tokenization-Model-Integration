# Bhojpuri Lite Adapter

## Bootstrap Information

- **Bootstrapped from:** Hindi
- **Language similarity:** 85%
- **Note:** Bhojpuri is mutually intelligible with Hindi

## Usage

This adapter was created by copying the Gurukul Lite adapter, which already
supports Hindi. 

Since Bhojpuri is 85% similar to Hindi,
the model can generate text in Bhojpuri using the same patterns.

## Performance

- **Expected accuracy:** 60-70% (bootstrapped, not specifically trained)
- **Can be improved:** Train on native Bhojpuri data when available

## Training Data

- Uses Gurukul Lite's training data (21 Indian languages)
- Relies on cross-lingual transfer from Hindi
