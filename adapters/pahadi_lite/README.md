# Pahadi Lite Adapter

## Bootstrap Information

- **Bootstrapped from:** Nepali
- **Language similarity:** 85%
- **Note:** Pahadi (Kumaoni/Garhwali) is very close to Nepali

## Usage

This adapter was created by copying the Gurukul Lite adapter, which already
supports Nepali. 

Since Pahadi is 85% similar to Nepali,
the model can generate text in Pahadi using the same patterns.

## Performance

- **Expected accuracy:** 60-70% (bootstrapped, not specifically trained)
- **Can be improved:** Train on native Pahadi data when available

## Training Data

- Uses Gurukul Lite's training data (21 Indian languages)
- Relies on cross-lingual transfer from Nepali
